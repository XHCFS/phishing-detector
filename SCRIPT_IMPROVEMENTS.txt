4. run.py (Python - CENTRALIZED RUNNER)
   Commands:
   - setup          Full setup (db + fetch + enrich)
   - db             Initialize database schemas
   - fetch          Fetch threat feeds
   - enrich         Enrich threat feed data
   - auth           Authenticate Gmail
   - emails         Fetch emails from Gmail
   - enrich-emails  Enrich fetched emails
   - api            Run FastAPI server
   - dashboard      Run Streamlit dashboard
   
   Features:
   - Comprehensive flags for all operations
   - Better than setup.sh with more control
   - Works with venv automatically
   - Cross-platform (no shell dependency)
   - Proper error handling

RECOMMENDED USAGE:
------------------

Primary (Cross-platform):
  python run.py setup                    # First time setup
  python run.py setup --fast-enrich      # Quick setup
  python run.py fetch                    # Update threat feeds
  python run.py enrich --limit 100       # Enrich 100 URLs
  python run.py auth                     # Authenticate Gmail
  python run.py api                      # Run API server
  python run.py dashboard                # Run dashboard

Bash users (if preferred):
  ./setup.sh                             # First time setup
  ./run.sh                               # Run API server
  ./run_dashboard.sh                     # Run dashboard

Fish users (if preferred):
  ./setup.fish                           # First time setup
  ./run.fish                             # Run API server
  ./run_dashboard.fish                   # Run dashboard
